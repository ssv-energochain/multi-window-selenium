# Multi-Browser Launcher

Скрипт для открытия нескольких независимых окон браузера с помощью Selenium. Доступны две версии: **GUI приложение** (рекомендуется) и **консольная версия**.

## Возможности

- Открытие нескольких независимых окон браузера одновременно
- Поддержка Chrome, Firefox и Yandex Browser
- Автоматическое открытие в полноэкранном режиме
- Изолированные профили Chrome/Yandex для каждого окна (клонирование базового профиля)
- Автоматическая установка расширений для Firefox
- Настройка через GUI или командную строку
- Автоматическая очистка временных профилей при закрытии
- Сохранение настроек (URL, браузер, количество окон, размер и положение окна)

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что у вас установлены браузеры Chrome, Firefox и/или Yandex Browser

3. Для Chrome: подготовьте базовый профиль в папке `chrome_profile/` (опционально, если нужны расширения/настройки)

4. Для Firefox: поместите расширения в формате `.xpi` в папку `extensions/`

5. Для Yandex Browser:
   - Скачайте [YandexDriver](https://github.com/nicknaz/nicknaz/blob/master/README_YandexDriver.md) и поместите `yandexdriver.exe` в корень проекта
   - Подготовьте базовый профиль в папке `yandex_profile/` (опционально)

## GUI версия (рекомендуется)

### Сборка exe файла

#### Способ 1: Через bat-файл (Windows)

```bash
build.bat
```

Скрипт автоматически:
- Создаст виртуальное окружение (если отсутствует)
- Установит зависимости
- Соберёт exe файл через PyInstaller
- Подготовит папку `dist/resources/` с необходимыми файлами

Готовый дистрибутив будет в папке `dist/`:
```
dist/
├── MultiWindowSelenium.exe
└── resources/
    ├── yandexdriver.exe
    ├── extensions/
    ├── chrome_profile_clones/
    └── yandex_profile_clones/
```

#### Способ 2: Через Python скрипт

```bash
python build.py
```

#### Способ 3: Через PyInstaller напрямую

```bash
pyinstaller build.spec --noconfirm
```

После сборки вручную скопируйте в `dist/resources/`:
- `yandexdriver.exe` (если используется Yandex Browser)
- Содержимое папки `extensions/`

### Использование GUI версии

#### Запуск из исходников

```bash
python gui_app.py
```

#### Запуск собранного exe

Просто запустите `dist/MultiWindowSelenium.exe` (или `MultiWindowSelenium.exe` из папки `dist/`).

#### Интерфейс

1. **URL страницы** — введите адрес для открытия (протокол `https://` добавляется автоматически, если не указан)
   - Чекбокс "Сохранять" — сохраняет URL в конфиг для следующего запуска

2. **Количество окон** — укажите число окон для открытия (только цифры)

3. **Браузер** — выберите из списка: Chrome, Firefox или Yandex

4. **Кнопки:**
   - **▶ Старт** — запускает браузеры с указанными параметрами
   - **■ Стоп** — закрывает все открытые окна браузеров
   - **🧹 Очистка** — удаляет все временные клоны профилей (полезно при ошибках)

5. **Статус** — отображает информацию о процессе запуска/остановки

#### Сохранение настроек

Приложение автоматически сохраняет:
- URL (если включён чекбокс "Сохранять")
- Браузер
- Количество окон
- Размер и положение окна

Настройки сохраняются в файл `config.json` рядом с exe (или в корне проекта при запуске из исходников).

#### Расположение ресурсов

- **При запуске exe:** ресурсы ищутся в папке `resources/` рядом с exe
- **При запуске из исходников:** ресурсы ищутся в корне проекта

Профили `chrome_profile/` и `yandex_profile/` создаются автоматически при первом запуске с 1 окном (см. раздел "Первый запуск и создание профилей").

## Консольная версия

### Способ 1: Через bat-файл (Windows)

```bash
run.bat
```

Запустит с настройками по умолчанию.

### Способ 2: Через командную строку

#### Базовое использование:
```bash
python main.py
```

Запустит с настройками по умолчанию (1 окно Firefox, открывает https://google.com).

#### С параметрами:
```bash
python main.py -u https://example.com -c 3 -b chrome
```

#### Параметры командной строки:

- `-u, --url` - URL для открытия (по умолчанию: `https://google.com`)
- `-c, --count` - Количество окон (по умолчанию: `1`)
- `-b, --browser` - Тип браузера: `chrome`, `firefox` или `yandex` (по умолчанию: `firefox`)

#### Примеры:

```bash
# Открыть 5 окон Chrome с указанным сайтом
python main.py -u https://example.com -c 5 -b chrome

# Открыть 3 окна Firefox
python main.py -u https://example.com -c 3 -b firefox

# Открыть 2 окна Yandex Browser
python main.py -u https://yandex.ru -c 2 -b yandex

# Короткая форма записи
python main.py -u https://yandex.ru -c 2 -b yandex
```

### Способ 3: Изменение настроек по умолчанию в коде

Откройте файл `main.py` и измените значения в строках 19-23:

```python
# ========== НАСТРОЙКИ ПО УМОЛЧАНИЮ (можно изменить здесь) ==========
DEFAULT_URL = "https://google.com"
DEFAULT_WINDOWS_COUNT = 1
DEFAULT_BROWSER = "firefox"
# ====================================================================
```

Например:
```python
DEFAULT_URL = "https://example.com"
DEFAULT_WINDOWS_COUNT = 5
DEFAULT_BROWSER = "yandex"
```

После этого просто запустите:
```bash
python main.py
```

## Настройка расширений

### Для Chrome:

1. Подготовьте базовый профиль Chrome с нужными расширениями и настройками
2. Поместите его в папку `chrome_profile/` в корне проекта (или `resources/chrome_profile/` для exe)
3. Скрипт автоматически создаст изолированные копии этого профиля для каждого окна

**Важно:** 
- Базовый профиль должен содержать все необходимые расширения и настройки
- Каждое окно получит свою независимую копию профиля в папке `chrome_profile_clones/` (или `resources/chrome_profile_clones/` для exe)
- Временные профили автоматически удаляются при закрытии окон
- При открытии 1 окна используется базовый профиль напрямую (без клонирования)

### Для Firefox:

1. Поместите файлы расширений в формате `.xpi` в папку `extensions/` (или `resources/extensions/` для exe)
2. По умолчанию используется расширение `extensions/cryptopro.xpi`
3. Для изменения списка расширений отредактируйте функцию `create_firefox_driver()` в `main.py` или `_create_firefox_driver()` в `browser_manager.py`:

```python
firefox_extensions = [
    os.path.abspath(os.path.join(os.path.dirname(__file__), "extensions", "cryptopro.xpi")),
    # Добавьте другие расширения здесь
]
```

### Для Yandex Browser:

1. Скачайте YandexDriver, соответствующий вашей версии Yandex Browser по ссылке [GitHub](https://github.com/yandex/YandexDriver)
2. Поместите `yandexdriver.exe` в корень проекта (или `resources/` для exe)
3. Подготовьте базовый профиль в папке `yandex_profile/` (или `resources/yandex_profile/` для exe) (аналогично Chrome)
4. Временные профили создаются в `yandex_profile_clones/` (или `resources/yandex_profile_clones/` для exe)

**Важно:**
- Yandex Browser использует тот же механизм, что и Chrome (форк Chromium)
- Расширения устанавливаются через профиль, как в Chrome
- При открытии 1 окна используется базовый профиль напрямую (без клонирования)
- Плашка "Браузером управляет автоматизированное ПО" скрыта

## Особенности работы

### Chrome:
- Каждое окно использует изолированную копию базового профиля (при count > 1)
- При открытии 1 окна используется базовый профиль напрямую
- Копии создаются в папке `chrome_profile_clones/` с уникальными именами
- Автоматически удаляются lock-файлы (SingletonLock, SingletonCookie и др.) для параллельной работы
- Временные профили автоматически удаляются при закрытии всех окон

### Firefox:
- Расширения устанавливаются автоматически при запуске
- Каждое окно работает независимо
- Расширения устанавливаются как временные (temporary=True)

### Yandex Browser:
- Работает аналогично Chrome (форк Chromium)
- Требует отдельного драйвера `yandexdriver.exe`
- Базовый профиль хранится в `yandex_profile/`
- Плашка "управляет автоматизированное ПО" отключена через excludeSwitches
- При открытии 1 окна используется базовый профиль напрямую

### Общее:
- Все окна открываются в полноэкранном режиме (maximized)
- После открытия всех окон (консольная версия) скрипт ждёт нажатия Enter для закрытия всех окон
- WebDriver Manager автоматически скачивает и управляет драйверами для Chrome и Firefox
- При ошибке открытия окна временные профили автоматически очищаются

## Первый запуск и создание профилей

### Поведение при отсутствии профиля

Если папки `chrome_profile/` или `yandex_profile/` не существуют:

| Количество окон | Поведение |
|-----------------|-----------|
| 1 окно (`-c 1`) | ✅ Профиль создастся автоматически. Браузер запустится с чистым дефолтным профилем. |
| 2+ окна (`-c 2` и более) | ❌ Ошибка `FileNotFoundError` — нечего клонировать. |

### Как создать и настроить профиль с нуля

#### Шаг 1: Инициализация профиля

Запустите скрипт с **одним окном** для нужного браузера:

```bash
# Для Chrome (GUI)
# Установите количество окон = 1, выберите Chrome, нажмите Старт

# Для Chrome (консоль)
python main.py -c 1 -b chrome -u https://google.com

# Для Yandex Browser (GUI)
# Установите количество окон = 1, выберите Yandex, нажмите Старт

# Для Yandex Browser (консоль)
python main.py -c 1 -b yandex -u https://google.com
```

Это создаст папку `chrome_profile/` или `yandex_profile/` с дефолтным профилем браузера.

#### Шаг 2: Настройка профиля

Пока окно браузера открыто, выполните нужные настройки:

1. **Авторизация на сайтах** — залогиньтесь на нужных ресурсах, cookies сохранятся в профиле
2. **Установка расширений** — установите расширения из магазина браузера (они сохранятся в профиле)
3. **Настройки браузера** — измените настройки, язык, масштаб и т.д.
4. **Сертификаты** — если нужно, установите корневые сертификаты

> **Важно:** 
> - **GUI версия:** Нажмите кнопку **"■ Стоп"** для корректного сохранения профиля
> - **Консольная версия:** Не закрывайте окно через крестик! Дождитесь завершения настройки и нажмите **Enter в консоли** — это корректно сохранит профиль.

#### Шаг 3: Использование с несколькими окнами

После настройки профиля можно запускать с любым количеством окон:

```bash
# GUI: просто укажите нужное количество окон и нажмите Старт

# Консоль: откроет 5 окон Chrome, каждое с копией настроенного профиля
python main.py -c 5 -b chrome -u https://example.com

# Консоль: откроет 3 окна Yandex с копией профиля
python main.py -c 3 -b yandex -u https://example.com
```

Каждое окно получит **независимую копию** базового профиля со всеми настройками, расширениями и авторизациями.

### Обновление профиля

Если нужно обновить профиль (добавить расширение, перелогиниться и т.д.):

1. **GUI:** Запустите с одним окном (count = 1), внесите изменения, нажмите Стоп
2. **Консоль:** Запустите с одним окном: `python main.py -c 1 -b chrome`
3. Внесите изменения в открывшемся браузере
4. **GUI:** Нажмите Стоп / **Консоль:** Нажмите Enter в консоли для корректного сохранения

Изменения сохранятся в базовом профиле и будут использоваться при следующих запусках.

### Использование существующего профиля Chrome/Yandex

Можно использовать профиль из вашего обычного браузера:

1. Найдите папку профиля браузера:
   - **Chrome (Windows):** `%LOCALAPPDATA%\Google\Chrome\User Data`
   - **Yandex (Windows):** `%LOCALAPPDATA%\Yandex\YandexBrowser\User Data`

2. Скопируйте нужный профиль (обычно `Default` или `Profile 1`) в папку проекта:
   ```bash
   # Пример для Chrome
   xcopy "%LOCALAPPDATA%\Google\Chrome\User Data\Default" "chrome_profile\Default\" /E /I
   ```

3. Закройте браузер перед копированием, иначе файлы будут заблокированы.

> **Внимание:** Профиль может занимать много места (сотни МБ — несколько ГБ). Для минимизации размера лучше создать чистый профиль через скрипт.

## Известные проблемы

### 1. Chrome: не устанавливается расширение КриптоПро

Расширение КриптоПро ЭЦП Browser plug-in использует устаревший Manifest V2, который Chrome больше не поддерживает. Установка расширения через `.crx` файл завершается ошибкой.

**Решение:** Для работы с подписанием КЭП (квалифицированной электронной подписью) используйте **Firefox** или **Yandex Browser** — в них расширение устанавливается корректно.

### 2. Yandex: лишние вкладки при повторном запуске

При работе с основным профилем (1 окно, без клонирования) Yandex Browser восстанавливает все ранее открытые вкладки. Это замедляет запуск и может вызывать зависания, пока не будет активирована стартовая вкладка.

**Решение:** Перед закрытием браузера (нажатием Стоп в GUI или Enter в консоли) закройте все вкладки, кроме одной. Держите в основном профиле только 1 открытую вкладку.

> **Примечание:** Эта проблема не затрагивает запуск с несколькими окнами (`-c 2` и более), т.к. клонированные профили удаляются после закрытия и всегда создаются заново из основного профиля.

## Примечания

- При первом запуске webdriver-manager автоматически скачает драйверы для Chrome и Firefox
- Для Yandex Browser драйвер нужно скачать вручную и положить в корень проекта (или `resources/` для exe)
- Если расширение Firefox не найдено, скрипт выдаст ошибку и остановится
- Если `yandexdriver.exe` не найден, скрипт выдаст ошибку при запуске с `-b yandex`
- **Консольная версия:** Для закрытия всех окон нажмите Enter в консоли (или Ctrl+C)
- **GUI версия:** Для закрытия всех окон нажмите кнопку "■ Стоп"
- Временные профили в `chrome_profile_clones/` и `yandex_profile_clones/` удаляются автоматически, но могут остаться при аварийном завершении (используйте кнопку "🧹 Очистка" в GUI)
- Базовые профили (`chrome_profile/` и `yandex_profile/`) не изменяются и не удаляются
- Настройки GUI сохраняются в `config.json` автоматически
